# GS-Aplicativo-Greencut-BETA-
Projeto desenvolvido com o intuito de modernizar e otimizar a detecção, coleta de dados e despache de equipes. O aplicativo Greencut foi desenvolvido para identificar regiões de mata alta em rodovias, a aplicação tem as funcionalidades de login, mapeamento, recebimento de informações da rodovia e despache de equipes para realizar a roçada.
